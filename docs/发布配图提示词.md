# 发布配图 · GPT 提示词（v2.0.0 / v2.0.1 / v2.1.0）

> 用途：GitHub Release 头图 / 创意工坊封面 / 更新公告配图。三张一套，同世界观、同配色、同纸感。

## 0. 用法要点

- **模型**：ChatGPT 直接生图，或 API `gpt-image-1`。API 只有三档尺寸：`1024x1024` / `1536x1024` / `1024x1536`，三张统一用 `1536x1024`，再裁成 GitHub 社交预览的 1280×640。
- **一张图一个会话**。三张连生会串味（第二、三张容易继承上一张的构图）。
- **每段提示词结尾都接同一段「风格尾缀」**，这是三张看起来像一套的关键。
- **别让模型写中文**。九成糊。标题留到 Figma / PS 里叠（思源宋体 SemiBold + 细英文副标），或只让它写 2–4 个字并做好重抽准备。
- **迭代一次只改一个变量**（机位 / 光源 / 母题），满意后把那张当参考图喂回去：「keep the same style and palette, change only the subject」。
- GPT 没有独立的 negative 参数，负面清单要写进正文末尾（见第 4 节）。

## 3. 逐张提示词

### 3.1 v2.0.0 · 衍天诀（开宗）

**EN**
```
Wide cinematic shot, low angle. A lone cultivator in layered pale-grey robes stands on a floating stone terrace above an endless sea of clouds, sleeves and hem lifted by wind. One hand is raised in a sword-finger seal; thousands of tiny luminous motes spiral up around the body and gather into a slowly rotating ring of faint glowing runes at shoulder height. Behind, a nine-tiered wooden pagoda library rises out of the mist, its lattice windows lit warm gold, the far side of the tower dissolving into brush-stroke ink wash. Distant peaks read as a few dry brush strokes. Mood: the founding of a sect — vast, silent, luminous.
```

**中文**
```
电影级广角仰拍。一名身着淡灰层叠长袍的修士立于云海之上的悬浮石台，衣袂被风吹起。他单手捏剑指，周身成千上万的细小灵光螺旋上升，在肩高处汇成一圈缓慢旋转的微光符文。身后一座九层木构藏书阁自雾中升起，格窗透出温暖金光，塔的远端化作水墨笔触消散。远山只用几笔枯笔表现。情绪：开宗立派——辽阔、静穆、通明。
```

**可替换项**：去掉人物 → 只留塔与云海（更适合作通用头图）；不想要塔 → 换成悬浮的巨型罗盘法阵。

### 3.2 v2.0.1 · 衍天珠（归元）

**EN**
```
Intimate close-up, shallow depth of field. A single luminous pearl the size of a pigeon egg hovers a hand's width above an open, weathered palm. Inside the pearl, a miniature nebula of jade-green meridians slowly turns around a gold core. Three thin threads of light leave the pearl and drift into the chest of a seated meditating figure, out of focus in the background, whose breathing shows as faint mist. Below: the edge of a dark rosewood workbench, a stone mortar, a few dried herbs. A faint circular halo of runes glows on the wood beneath the pearl. Mood: warmth returning to a tired body — quiet, intimate, restorative.
```

**中文**
```
近距离特写，浅景深。一颗鸽卵大小的灵珠悬浮在摊开、粗糙的手掌上方一寸处。珠内是一团微缩星云：玉青色经络绕着一枚金核缓慢旋转。三缕细光从珠体逸出，飘向背景中虚焦的盘坐修士胸口，呼吸化作淡淡白雾。下方是深色红木台面的一角、石臼、几味干药材。珠下木面映出一圈极淡的符文光晕。情绪：温热回到疲惫的身体——安静、私密、修复感。
```

**可替换项**：不要人 → 纯器物静物（珠 + 手 + 木台），更像物品图鉴；要更"剧情" → 珠悬于丹炉上方，炉口青焰。

### 3.3 v2.1.0 · 灵道剑（藏锋）

**EN**
```
Dark-void hero shot. A slender Chinese straight sword (jian) floats point-down, perfectly still; along the blade runs a line of tiny glowing rune nodes, each a small notch of white light. Forty-nine small spirit stones orbit the blade in a slow, tilted ring, trailing faint blue threads. A single thread of ink-black qi is drawn from the chest of a robed figure standing at the left edge in shadow, arcing into the blade; where it enters, the steel brightens. The figure's face is not visible. Mood: cold, sharp, patient accumulation of power.
```

**中文**
```
暗场主视觉。一柄修长的中式直剑倒悬半空、纹丝不动；剑脊上排着一列细小发光的符文节点，每一枚都是一道白色光的小刻痕。四十九枚小灵石以缓慢倾斜的环围绕剑身旋转，拖出淡蓝细丝。一缕墨黑的道行之气自画面左缘阴影中修士的胸口被抽出，成弧线没入剑身；入剑处钢色转亮。修士的面部不可见。情绪：冷、利、耐心积攒的力量。
```

**可替换项**：不要人 → 剑悬于墨色水面，倒影被剑锋切开；要更"特写" → 剑锋从两指之间被缓缓推出，背景全黑。

## 4. 负面清单（追加到每段末尾）

```
Avoid: any text, letters, characters, watermark, logo, signature; extra fingers, deformed hands, warped faces; modern objects (phones, neon, sneakers); western medieval armor or gothic architecture; oversaturated colours; cluttered composition; heavy lens flare; blurry or low-detail areas.
```

## 5. 出图后的排版与验收

- **裁切**：1536×1024 → 居中偏右裁 1280×640；主体落在右 60%，左 40% 留标题。
- **标题层**：中文主标 64–72px（思源宋体 SemiBold，字距 +2），英文副标 18px 全大写、字距 +6、透明度 60%。
- **三张并排验收**：① 纸纹与颗粒强度是否一致；② 光是否都从左上来；③ 是否都只有一处金色；④ 缩到 320px 宽时是否还能一眼认出母题。
