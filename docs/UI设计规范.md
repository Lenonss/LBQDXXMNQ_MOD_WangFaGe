# UI 设计规范（万法阁 · FairyGUI 窗口）

> 本文件是**规范性文档**，只写“必须 / 禁止 / 建议”。故障现象、根因和修复过程见 [开发经验 · UI 与部署](开发经验-UI与部署.md)，框架能力见 [研究-官方UI框架手册](研究-官方UI框架手册.md)。
>
> 适用范围：衍天数据中心、衍天能源中心、创造窗，以及后续所有基于官方 RemoteStorage 壳的 FairyGUI 窗口。
>
> 维护规则：技能侧规则在 **references/11-ui-design.md**；本项目 token、尺寸和验收项以本文件为准。改任一侧必须同步另一侧，并在 [开发日志](开发日志.md) 留一条记录。

## 1. 三条总原则

1. **先壳后内容**：先确定官方窗口壳的 contentPane 与网格区，再往里放控件；禁止先按设计稿写死坐标，最后再让窗口适配。
2. **尺寸从运行时实测值推导**：窗口宽度、网格宽度、底栏位置都以日志里的 pane/grid 为准；基准值只是起点，不是绝对坐标。
3. **先规则后控件**：新增界面前先过本文件第 6 节验收清单；控件能画出来不等于布局成立，必须同时满足不超框、不重叠、可读、可点、可关闭。

## 2. 基准壳与设计 token

当前官方 RemoteStorage 壳的实测基准（以 `[ui:<key>] shell pane=... grid=...` 日志为准）：

| 项目 | 基准值 | 说明 |
|---|---:|---|
| contentPane | 470 × 524 | 窗口内容区，不是屏幕；不要 SetSize/SetScale 整个窗口 |
| grid | x=21, y=94, 439 × 378 | 初始网格区；页签/筛选会改变 y 与高度 |
| 内容内边距 | 8 px | 筛选条、浮层、提示至少留 8 px |
| 浮层外边距 | 10 px | 弹出面板与窗口边框的安全距离 |
| 间距阶梯 | 4 / 8 / 12 / 16 px | 同级控件优先 8 px |
| 控件高度 | 28 / 30 / 32 px | 操作按钮 28，筛选触发器 30，页签容器 32 |
| 边框 | 1 px | 深棕；不要用粗黑边 |
| 阴影 | 4 px | 仅浮层/浮窗，右下方向，半透明 |
| 能源面板 | 428 × 428 | panel x=21, y=72；正文区 428 × 180 |
| 工具提示 | 310 px 宽 / 282 px 正文 | 固定宽度，手动断行，不依赖 wordWrap |

颜色 token（当前实现值，改色必须同步本表）：

| 用途 | 颜色 |
|---|---|
| 控件底色 | Color(0.99, 0.95, 0.85, 1) |
| 控件边框 | Color(0.55, 0.42, 0.25, 1) |
| 正文 | Color(0.23, 0.16, 0.08, 1) |
| 浮层面板 | Color(0.985, 0.955, 0.885, 1) |
| 浮层边框 | Color(0.50, 0.37, 0.21, 1) |
| 选中底 | Color(0.955, 0.885, 0.715, 1) |
| 阴影 | Color(0.12, 0.08, 0.03, 0.22) |

禁止大面积纯黑/纯白；不要用高饱和色表达“可点”，用边框、底色层次和文字提示表达。

## 3. 结构规则

### 3.1 标题 / 页签

- 标题使用壳自带的 m_title，不另画标题栏。
- 页签 3–6 个；超过 6 类时合并为“其他”或做二级分类，禁止把页签压到不可读。
- 页签必须显示当前选中态；选中态不能只靠颜色，至少同时有底色变化。
- 页签容器与筛选条之间至少 8 px。

### 3.2 顶部筛选

- 筛选最多 **2 行**；每行 1–2 个触发器，总计 3–4 个。超过 4 个时增加“更多筛选”浮层，不要继续压缩宽度。
- 筛选条整体按 **gridW - 16** 收窄，左右各留 8 px；触发器总宽不得超过这个值。
- 单枚触发器最小宽度 **120 px**；低于 120 px 时改为分行或“更多”，禁止把“五行：全部”压成省略号。
- 两行布局用 2+1 或 2+2；行高 32、行距 6；网格起点在筛选条下方至少 8 px。
- 每枚触发器必须同时显示 **字段名 + 当前值 + 箭头**（如“品质：全部 ▾”），不能只显示字段名。
- 点击切换一律用 **二级浮窗/下拉**；禁止用“点一下换下一个值”的循环按钮。
- 触发器宽度要按当前行实际按钮数均分并居中；不要用固定 154 px 的原生按钮宽度硬塞。

### 3.3 网格与卡片

- 卡片使用官方 Bnt_EquipItem 组件，不自行缩放卡片；需要更大信息量时用浮窗，不拉长卡片。
- 卡片至少显示：图标、名称、品质；创造页不显示库存数字，数据中心可显示共享总库信息。
- 网格间距至少 8 px；卡片不得越过网格区右边界和底栏。
- 空态文字放在网格区垂直中部，不要贴在顶部或盖住底栏。
- 底栏单独占一行，高度 24–28 px；不要和最后一行卡片重叠。

### 3.4 底栏

- 只放一行摘要/操作提示；超长时先缩短文案，不要靠缩小字号。
- 底栏文字与网格之间至少 4 px；底栏必须完整落在 pane 内。

## 4. 控件规则

### 4.1 精确宽度按钮（筛选、能源操作）

必须用自绘扁平按钮，不要用原生 UI_bnt_buildType 缩放：

~~~lua
btn = CS.FairyGUI.GButton()
btn:SetSize(w, h)
btn.opaque = true          -- 整块可点
btn.touchable = true
bg = CS.FairyGUI.GGraph()
bg:DrawRect(w, h, 1, lineColor, fillColor)  -- 第 4 线色，第 5 填充色
bg.touchable = false
btn:AddChild(bg)
label = CS.FairyGUI.GRichTextField()
label.autoSize = CS.FairyGUI.AutoSizeType.None
label:SetSize(w, h)
label:SetXY(0, 1)
label.align = CS.FairyGUI.AlignType.Center
label.touchable = false
label.text = text          -- 最后单独赋值
btn:AddChild(label)
~~~

- 背景或文字创建失败时，必须有占位子件，保证文字始终是 child 1。
- 不要在同一个 pcall 里先设未暴露属性再设 text；属性失败会中断后续 AddChild，表现为“只有底板没有字”。
- 按钮显示/隐藏后必须按 **可见按钮** 重新居中；隐藏按钮不能继续占位。

### 4.2 原生控件

- 用官方内置件时必须先转类型：GList 用 asList，GButton 用 asButton，GTextInput 用 asTextField，GSlider 用 asSlider；AddItemFromPool 返回 GObject，不转类型就设属性会静默失败。
- 原生按钮只在“不需要精确宽度”时使用；一旦 SetSize 与原生九宫格图形不一致，禁止使用。
- 池化复用前清 onClick/onRollOver/onRollOut 并重置 selected；否则旧闭包会串到新数据。

### 4.3 滑条

- 用 UI_SliderH，并先 asSlider。
- 先设 min < max，再设 value；min == max 会产生 NaN，显示 -nan(ind)。
- 程序设置 value 不触发 onChanged；只有拖动/点击才触发。需要同步标签时自己做，且用 syncing 标志防递归。
- 滑条隐藏/显示后重新布局；标签、数值、滑条三段不能互相压住。

### 4.4 文本与富文本

- 需要整宽居中或固定宽排版时，先设 **autoSize=None**，再 SetSize，最后写 text；默认 autoSize=Both 会把控件缩成文字宽度，视觉上偏左。
- 字号属性是 **fontsize**（小写）；没有 camelCase 的 fontSize。
- 没有 **wordWrap**；长文本用 UTF-8 安全函数按字符手动插 `<br/>`。
- GRichTextField 只认 HTML；不要写 UBB 的 `[color=#...]`，会原样显示。
- 长名称/描述按每行 22 个中文字符断行；断行后必须用 textHeight 复核高度，预留至少 1 行余量。

### 4.5 浮层与下拉

- 展开前先向 contentPane 加全屏透明 blocker：opaque=true、touchable=true，点击只关闭浮层。
- 浮层必须加在 blocker 之后；关闭时先 Dispose blocker，再 Dispose 浮层。
- 点击触发器再点一次也关闭；关闭后箭头恢复“▾”。
- 浮层位置用父控件局部坐标相加；必须同时传入触发器顶边 anchorTop，空间不足时用 anchorTop - 浮层高度 - 10 向上翻。
- 浮层夹在 pane 内 10 px；不要越过窗口边框。
- 选项回调先关闭浮层，再执行业务刷新；不要在浮层存活时重建网格。

### 4.6 工具提示

- 固定 310 px 宽、正文 282 px；不要按内容自动变宽。
- 名称、类别、描述、提示都按 22 字手动断行；用 textHeight 反算高度，取不到时按字符数估算。
- 定位顺序：右侧 → 卡片下方 → 卡片上方；禁止翻到卡片左侧遮住卡片，否则会触发 rollOut 闪烁。
- 最终位置夹在 pane 内 8 px；提示层 touchable=false。

## 5. 交互与状态

- **角色门禁放在所有显示入口**：不仅按钮点击处，Show/OpenNpc/选择角色回调都要检查；拒绝时清空当前角色、关闭已开窗口，只弹提示。
- 打开窗口时暂停，关闭时恢复；重复 Show/Close 必须幂等。
- 显隐切换后重排；空态、错误态、禁用态都要有文字，不能只靠颜色。
- 当前值必须可见：模式、阈值、限额、单次量、已选落点等写在正文或按钮上。
- 关闭浮层/窗口后不得留下可点击的透明层。

## 6. 验收清单（新增/改界面逐条过）

- [ ] 窗口居中，contentPane 未被 SetSize/SetScale 拉伸。
- [ ] 所有控件在 pane 内，左右上下各留至少 8 px；没有控件压住窗口边框。
- [ ] 筛选不超过 2 行，触发器不重叠、不超宽、文字完整；每枚都有字段名+当前值+箭头。
- [ ] 筛选浮层可打开、可选择、点外部关闭、再点触发器关闭；选中项有非颜色标记。
- [ ] 网格卡片不被筛选条/底栏遮住；空态在网格中部。
- [ ] 能源正文每行真正居中；滑条标签/数值/轨道不重叠；按钮按可见项居中。
- [ ] 工具提示最长文案不超框、不遮住正在悬停的卡片。
- [ ] 创造页卡片和浮窗都没有库存数字；数据中心仍保留共享总库信息。
- [ ] 未修炼衍天诀的角色从任意入口都打不开能源中心，只弹提示；已开窗口会关闭。
- [ ] 关闭窗口后暂停恢复；再次打开不残留旧浮层/旧箭头/旧回调。
- [ ] luac 全量通过；acs_mod.py check 0 错 0 警；deploy 文件数正确；verify_deploy 43/43 SHA-256 全同。
- [ ] 完全退出游戏后重启，三窗各开一次，日志无“初始化失败/控件不是按钮/监听挂载失败”。

## 7. 禁止清单

1. 禁止对整个 Window 调 SetSize/SetScale；窗口尺寸由官方 contentPane 决定。
2. 禁止用固定 154 px 的原生按钮硬塞三枚筛选；总宽超过 gridW 就是超框。
3. 禁止用循环按钮表达多值筛选；必须用下拉/二级浮窗。
4. 禁止在 GRichTextField 里写 UBB 标记。
5. 禁止写 GTextField.fontSize 或 wordWrap；它们没有暴露。
6. 禁止在同一个 pcall 里先设装饰属性再设 text；文本必须最后单独赋值。
7. 禁止工具提示翻到悬停卡片左侧遮挡卡片。
8. 禁止只在按钮点击处做角色门禁；Show/选择回调也必须拦。
9. 禁止没有 blocker 的浮层；点外部无法关闭会显得“卡死”。
10. 禁止在 ClearCards 里顺手清空 rows；数据源和控件生命周期必须分开。

## 8. 变更流程

1. 先在日志里量当前 pane/grid，记录 `[ui:<key>] shell pane=... grid=...`。
2. 改本文件的 token 或规则；同步技能侧 **references/11-ui-design.md**。
3. 再改代码；所有尺寸从 pane/grid 推导，不凭截图估。
4. 跑 luac、acs_mod.py check、deploy、verify_deploy；不启动游戏。
5. 用户完全重启后实机验收；截图/日志回填开发日志。
6. 规则变更写进开发日志；不要在经验文档里另立一套冲突规则。
