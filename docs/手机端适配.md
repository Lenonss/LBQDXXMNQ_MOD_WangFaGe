# 手机端（安卓）适配说明

> 当前状态：**代码侧改造已完成，真机验证未做**。下文「验证步骤」必须在安卓设备上跑一遍才算数。

## 1. 先搞清楚一件事：手机版能不能跑这个 mod

官方安卓版（包名 `com.GSQ.XiaWorld.googleplay`）确实支持 Mods 目录，社区反馈是「部分 PC 模组可用」，
带快捷键/额外菜单的模组大概率不生效；本模组零热键（全靠神通按钮进入界面），是相对有利的一类，
但「移动版是否加载 Lua 脚本」「是否内置 SimpleWindow 等辅助模块」没有公开资料，**只能实测**。

实测用探针包，两分钟出结论：

1. 把 `tools/probe_mod` 整个文件夹拷到手机 Mods 目录，改名为 `WFGProbe`（见第 2 节路径）；
2. 启动游戏 → 模组列表里激活「WFG 探针」→ 进存档；
3. 会弹一个写着 `[WFGProbe] ...` 的窗，或者进游戏后看日志里的 `[WFGProbe]` 行。

判定标准：

| 探针输出 | 结论 | 对策 |
| --- | --- | --- |
| 完全没有 `[WFGProbe]` 行 | 移动版不加载 Lua | 本模组无法上手机，只能做纯 XML 内容版 |
| 有输出且 `SimpleWindow=table`、`MagicHelper=table` | 环境齐备 | 直接按第 3 节装正式包 |
| 有输出但 `SimpleWindow=nil` | 缺内置依赖 | 走「自带窗口实现」分支（见第 5 节） |
| 有输出且 `grootSize` 与 `screen` 比例差异大 | 逻辑分辨率不同 | 需要按 `contentScaleFactor` 做自适应布局 |

把弹出的文字（或截图）发回来即可，里面已经包含平台、分辨率、DPI、触摸支持、三个依赖是否存在、FairyGUI 缩放因子。

## 2. 安装路径

**电脑（Steam）**

```
<Steam>\steamapps\common\AmazingCultivationSimulator\Mods\万法阁\
```

**安卓**

```
/storage/emulated/0/Android/data/com.GSQ.XiaWorld.googleplay/files/Mods/万法阁/
```

- 4399 等渠道包的包名可能不同，路径里的 `com.GSQ.XiaWorld.googleplay` 换成实际包名即可。
- `files` 下如果没有 `Mods` 文件夹，自己新建一个；每个模组一个独立子文件夹。
- Android 11+ 系统文件管理器看不到 `Android/data`，需要 Shizuku、FV 文件管理器、或用数据线在电脑上操作。
- 拷完进游戏 → 模组列表 → 勾选「万法阁」→ 重启生效。

## 3. 更新怎么保证

仓库：<https://github.com/Lenonss/LBQDXXMNQ_MOD_WangFaGe>

- 每次发版在 **Releases** 里出一个 zip（PC 与安卓通用），解压后是 `万法阁/` 目录，整份覆盖到 Mods 下；
- 同步文件清单在 Release 附带的 `SHA256SUMS.txt`；
- 覆盖更新不会影响存档（存档在游戏的 Saves 目录，与 Mods 无关）。

发版流程见仓库根目录 `README.md`「发版」一节，一条 tag 触发 GitHub Actions 自动打包。

## 4. 卡住了怎么看日志

**安卓**

```
adb logcat -s Unity:* Lua*:* > wfg_android.log
```

或直接在手机上用 MatLog 一类工具抓 logcat。Lua 报错通常出现在 `[LuaException]` 或 `LuaStack` 附近。

**电脑**：`%USERPROFILE%\AppData\LocalLow\GSQ\Amazing Cultivation Simulator\Player.log`

常见症状对照：

| 症状 | 可能原因 |
| --- | --- |
| 模组列表里激活了，但游戏里没有任何入口 | 移动版没有神通页签 → 需要加建筑/物品入口 |
| 点神通没反应，日志无报错 | `MagicEnter` 未被调用，或 `WEG.ui` 初始化失败（看 `WFG` 启动日志） |
| 窗口弹出但超出屏幕 | 逻辑分辨率与固定像素尺寸不匹配（`WIN_W/WIN_H` 硬编码） |
| 点按钮没反应，但电脑上正常 | 触屏事件没走 `onClick`，或被 `mouseEnabled` 拦下 |
| 输入框点开不出键盘 | FairyGUI 的 TextField 在移动端需要 `TouchScreenKeyboard` 支持 |

## 5. 已知限制（截至本版）

1. `Scripts/WFG/ui/fgui_browser.lua` 与 `hall_window.lua` 已用官方 FairyGUI 壳，不依赖 SimpleWindow；
   其余窗口（主界面、取名、衍天、凝珠、落点选择）仍走内置 `SimpleWindow`。
2. 落点选择 `pos_picker.lua` 用鼠标左/右键与 Esc，触屏下需要改成单击确认 + 返回键取消。
3. 行悬停高亮（`onRollOver`）与 3 秒悬停提示在触屏上无效，需改为长按或点按弹出。
4. 窗口尺寸为固定像素，小屏手机上可能溢出，需要按 `GRoot` 逻辑宽高做上限钳位。
5. 快捷键系统完全没有实现（`OnSetHotKey` 返回空表），这一点对手机是好事。

以上 2–4 项是否必须改，取决于第 1 节探针结果与真机截图。
