# 万法阁

《了不起的修仙模拟器》(v0.995) 综合功法模组。首门功法：仙修「衍天诀」。PC（Steam）与安卓版共用同一份内容。

## 下载与安装

到 [Releases](https://github.com/Lenonss/LBQDXXMNQ_MOD_WangFaGe/releases) 下载最新的 `WangFaGe_vX.Y.Z.zip`（资源包文件名是 ASCII，解压后仍是 `万法阁/` 文件夹），整份放进游戏的 Mods 目录，进游戏「模组」勾选后**重启游戏**。

- **PC**：`...\Steam\steamapps\common\AmazingCultivationSimulator\Mods\万法阁\`
- **安卓**：`/storage/emulated/0/Android/data/com.GSQ.XiaWorld.googleplay/files/Mods/万法阁/`
  （渠道包包名可能不同；`files` 下没有 `Mods` 就自己新建；Android 11+ 手机上需 Shizuku / FV 文件管理器才看得到 `Android/data`）

更新：下载新 zip 覆盖同名文件夹即可，不影响存档（存档在游戏 Saves 目录，与 Mods 无关）。

源码开发期可用 `python tools/deploy.py` 覆盖式同步到本机游戏目录（`--dry` 只预览）。

## 安卓兼容性

本模组零热键（所有界面入口都是神通按钮），不用文件读写、不用网络，属于较容易移植的一类；
但移动版是否加载 Lua 脚本、是否内置 `SimpleWindow` 等辅助模块仍需真机确认。
诊断方法（探针包）、安装路径与已知限制见 [手机端适配说明](docs/手机端适配.md)。

### 程序
- **自愈程序**（结丹期可学、第 6 境灵子飞升起生效）：持续回复（每帧少量结算，不会溢出浪费），状态栏常驻「自愈程序」效果；灵气未满时优先回灵（灵气行显示 +X/秒），满后溢出转气血；基础 4% / 1.5%，每境递增，精研本 ×1.5（精研本金丹期可学）。
  神通按钮随开关切换「自愈程序·开启 / ·关闭」（图标与文案都变），点击不再弹窗，结果只写日志。
- **避天机程序**（元神期可学、第 10 境避天机起生效）：`NeckCountdownAddV +99999999` 冻结天劫倒计时；面板「天机」页选「留世渡劫 / 登仙而去」，再点「引动雷劫」。
- **衍天**（结丹期可学、第 9 境衍天境起生效）：解析物品入素材库（等阶/品级决定成本），创造按 30% 成本计，批量 ≥10 打九折、上限 20 / 100 件。
- **炼石**（结丹期可学）：发动后每 20 秒凝结 1 枚灵石，每枚消耗 5000 灵气；当前灵气不足 5000 时停止。
- **本命法宝**：学会秘籍「本命法宝·总纲」后解锁三柄本命飞剑的官方法宝炼制；炼成后先装入人物道具槽（秘宝固定占用「道具」格），由衍天诀修士右键完成认主（认主后进入法宝格）。衍天数据中心/衍天能源中心的管理入口在对应的奇观建筑上，不再占用神通按钮。法宝格随境界逐步解锁（累计 6）。

### 本命法宝 · 灵析剑 / 灵源剑 / 灵道剑
三柄飞剑都是真实法宝物品，走游戏原生的法宝炼制流程；本 mod 只负责在学会总纲后解锁配方。刚炼成的是法宝胚胎，装备后还要在人物道具槽（「道具」格）中右键认主；激活条件是「修行衍天诀」，其他功法会停在 0/1，无法认主；衍天诀把剑装入道具槽后约 1 秒进度到 1/1，即可右键认主。**只有功法为衍天诀且佩带已认主的对应飞剑时**，界面功能与属性加成才生效；其他功法即使强行装备也只是普通法宝。

| 法宝 | 功能 | 说明 |
|---|---|---|
| 灵析剑 | 素材自动同步 | 佩带后个人素材库与衍天数据中心每秒双向并集同步：自己解析的素材汇入总库，总库中他人所录之物补入个人库（标记为借用）。卸下后借用条目自动移出，自己解析的保留。 |
| 灵源剑 | 能源核心 | 佩带后可存取衍天能源中心的灵气，并让核心自动供灵。容量 1 亿。 |
| 灵道剑 | 道行存取 | 佩带并认主后指令栏出现「灵道剑」，可把自身道行存入剑内或取回；每 1 点存道使法宝威力 +1%，**没有上限**，加成作用于佩者全部法宝。 |

能源核心两种供灵模式：
- **实时获取**：灵气低于阈值（默认 60%）补到阈值，累计取用达限额（默认 100 万）后停止，需「重置限额」。
- **充满获取**：灵气见底时一次取设定量（默认 1 万）。

两柄剑佩带后大幅提升气血、灵气上限、寿元、身法、修炼/悟性/吸收与护盾、五行抗性；灵源剑额外强化法宝威力、术法威力、飞行与击退，并大幅降低法宝吸灵。加成只在衍天诀角色身上挂载，卸下或转功法即移除。

灵道剑是第三柄本命飞剑：炼制需 **1 颗衍天珠 + 49 灵石**。佩带并认主后，角色指令栏出现「灵道剑」按钮（未佩剑但剑内仍有存道时按钮保留，只允许取回）。存入的道行从自身道行扣除、被剑占住，不能再用于修行；取回时原额返还。存道记在修士自身而非剑上——换剑、卸下甚至转修他法都不会丢失，转修后加成失效但仍可取回。加成走角色级属性 `NpcFight_FabaoPowerAddP`，因此同时作用于该修士的所有法宝。

**旧存档兼容**：秘籍的配方是在「学会总纲的那一刻」写进角色的，所以已学过总纲的老角色进游戏后 1 秒内会自动补学灵道剑配方，无需重学秘籍（判定依据是参悟树节点「本命法宝」，即 `IsLearnedTreeUnit`）。但新增的物品种类与配方表只在游戏启动时加载——更新后必须**完全退出游戏再启动**（不是读档），否则炼制列表里仍然只有两柄旧剑。

### 衍天珠
修衍天诀者可用神通「凝练衍天珠」以 **500 灵气/颗** 凝练，弹窗内用滑条选择本次数量（上限为当前灵气可负担的颗数）。衍天珠有四种用途：

- **服用**：立刻恢复 10% 最大灵气；并从根本灵气上永久 +25%（即灵气上限 +25% 基础值），**最多生效 4 次**；尚未入门的智慧生灵服用可 +10000 筑基值（筑基需 25000，约 40%）。
- **佩带**：心境 +100，伤势自然恢复速度 +50%，并每秒回复 0.3% 最大气血与 1% 最大灵气。
- **炼器**：炼制灵析剑需 3 颗、灵源剑需 9 颗、灵道剑需 1 颗，替代原玄牝珠需求；另需 10 / 100 / 49 灵石。
- **聚灵**：放置后对周围 5×5（半径 2）提供聚灵，强度按原版最高档聚灵物（`AddionLing=200`）计；随身携带或放在背包不生效。

凝练出的衍天珠是普通物品，可堆叠（每格最多 99 颗）、放置、交易或交给同门；但只有衍天诀修士能通过凝练神通产出。

### 衍天佩
手工台制作：**1 枚衍天珠 + 10 份任意木料**（工作 300）。佩带后按已学衍天诀技能逐项解锁增幅；多数为原效果翻倍，本命法宝为额外 +100% 法宝威力（原节点只解锁配方）。未学会的技能不生效，卸下后加成消失。共 14 项：

| 已学技能 | 衍天佩解锁 |
|---|---|
| 总纲 | 灵气上限增幅翻倍（+100% → +200%） |
| 自愈程序 | 回灵/回血速率翻倍 |
| 自愈·精研 | 精研加成翻倍（+50% → +100%） |
| 解析 | 解析耗灵减半 |
| 创造 | 创造耗灵减半（与解析独立计算，不叠乘） |
| 本命法宝 | 佩版额外 +100% 法宝威力（原节点只解锁配方） |
| 避天机 | 劫数延后与法宝位加成翻倍 |
| 炼石 | 解锁主动神通「衍天·炼石（佩）」 |
| 御剑 | 法宝威力 +30%→+60%，飞行/转向 +20%→+40% |
| 灵盾 | 护盾转化 +30%→+60%，气血 +10%→+20%，回复 +20%→+40% |
| 器谱 | 炼器速度 +30%→+60%，成功率 +10%→+20%，品质 +5%→+10%，灵性 +20%→+40% |
| 周天 | 修炼 +50%→+100%，悟性 +30%→+60%，吸收 +30%→+60%，心境 +30→+60 |
| 锋锐 | 法宝威力 +80%→+160%，术法 +40%→+80%，法宝回灵 +50%→+100%，冷却 -15%→-30% |
| 不灭 | 气血 +25%→+50%，回复 +40%→+80%，护盾转化 +25%→+50% |

**炼石（佩）是主动神通**：佩带并已学炼石后，指令栏出现「衍天·炼石（佩）」，点击才开始运转；每 10 秒凝 1 枚灵石、每枚扣 5000 灵气，灵气不足或主动停止即结束。未点击不会自动产石，原「衍天·炼石」（20 秒/枚）仍保留。主面板「总览」会显示衍天佩是否佩戴、已学技能数与解锁摘要。

### 衍天数据中心与衍天能源中心（奇观）
两座共享建筑改为**奇观**，不再是参悟树技能：选择任一「万法阁」开局经历（如「万法阁·衍天传人」）后由 Lua 自动解锁，可在「建造 → 奇观」中找到。设计上各只建一座；建筑本身提供管理入口，但总库功能不依赖座数。

| 建筑 | 形制 | 占地 | 建造消耗 |
|---|---|---|---|
| 衍天数据中心 | 应天台 | 2×2 | 衍天珠 ×9 + 任意金属锭 ×999（工作 3000） |
| 衍天能源中心 | 灵玉峰 | 5×3 | 衍天珠 ×9 + 任意金属锭 ×999（工作 6000） |

## 操作
- 神通「万法阁」打开面板（总览 / 素材库 / 天机）。
- 神通「凝练衍天珠」打开凝练窗：滑条选择数量，确认后扣除灵气并把衍天珠放到施术者附近。
- 点击「衍天数据中心」建筑上的「管理」，直接打开素材总览（不显示角色信息）。
- 点击「衍天能源中心」建筑上的「管理」，先选择场景中的角色，再打开该角色的能源管理界面；也可在佩带已认主灵源剑的衍天诀角色指令栏点「衍天能源中心」直接打开。未修炼衍天诀的角色会被门禁拦下，只弹提示、不打开界面。
- 能源界面可调整该角色自己的供灵模式、补灵阈值、累计限额、单次取用量，并重置已用限额；模式切换走二级浮窗，参数用滑条。存入/取用与自动供灵需衍天诀且佩带已认主灵源剑。
- 佩带已认主灵道剑的衍天诀角色，指令栏出现「灵道剑」：用滑条选择数量后「存入道行 / 取回道行」，存入超过当前道行一半会要求二次确认；每 1 点存道 +1% 法宝威力且无上限。未佩剑或已转修他法时只能取回，存道不会丢失。
- 数据中心与创造窗的顶部筛选为两行下拉触发器（品质 / 品阶 / 五行），点击展开二级选项面板；点击面板外任意位置或再次点触发器即可关闭。创造页卡片只显示品质，不显示库存数量。
- 神通「衍天·解析」对准物品施放。
- 神通「避天机·渡劫」直接引动雷劫（面板流程更稳）。
- 自愈 / 解析 / 创造 / 凝练四枚神通按钮使用自制图标（`Resources/wfg_skill_*.png`）；自愈关闭态为同图的去色版，一眼能看出开关。图标统一由根目录 `make_icons.py` 处理成 128×128 圆形透明 PNG，并重建 `res/preview_skill_icons*.png`。

## 已知边界
- 秘籍 `StarLevel` 必须是 0–2，否则参悟树整片空白。
- 主面板为 SimpleWindow 拼装（无自定义 fui 包），交互用对话框选项代替输入框。
- 建筑唯一性目前只做提示，不做硬拦截。

## 开发与发版

```bash
python tools/check_compat.py          # 双端静态体检：编码/BOM、反斜杠路径、资源大小写、触屏风险清单
python tools/package_release.py       # 打 dist/WangFaGe_vX.Y.Z.zip 与 dist/SHA256SUMS.txt
python tools/bump_version.py 2.1.0    # 改版本号（Info.json Version=210）
python tools/deploy.py                # 开发期覆盖同步到本机游戏 Mods
python tools/verify_deploy.py         # 逐文件 SHA-256 比对
```

**发版**：改版本号 → 在 `CHANGELOG.md` 顶部补一节 → 提交 → 打 tag 推送：

```bash
git tag v2.1.0
git push origin main --tags
```

GitHub Actions（`.github/workflows/release.yml`）会自动跑体检、打包并发布 Release，zip 同时适用于 PC 与安卓。

版本号映射：`Info.json` 的整数 `Version` = major×100 + minor×10 + patch（`2.1.0 → 210`）。游戏内只显示整数，GitHub 上用语义化 tag。

**目录结构**：`Settings/` 数据表 · `Scripts/` Lua · `Resources/` 图片资源 · `tools/` 构建与校验脚本 · `docs/` 设计与开发文档 · `res/` 设计源图。
